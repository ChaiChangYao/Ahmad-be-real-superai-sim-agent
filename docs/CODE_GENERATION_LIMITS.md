# Code Generation Limits

## Can Be Generated Reliably From Text
- Physics manifest JSON and schemas
- URDF/MJCF robot descriptions
- Component/material/sensor/wire profiles
- Control scripts and scenario definitions
- Procedural Three.js robot visuals
- Simplified collision primitives for Genesis

## Cannot Be Reliably Produced From Text Alone
- Production-grade industrial STEP assemblies with exact NURBS and manufacturing detail
- Exact proprietary robot geometry
- Certified FEA/thermal/electrical/safety validation outputs
- Perfect CAD auto-joint inference for arbitrary assemblies

## Product Implication
- Default procedural robot dog proves local simulation product value without uploads.
- Uploaded CAD improves realism when available.
- Source CAD import remains optional advanced workflow.
